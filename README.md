# ESP32_Battery_Dev_Board
The purpose of this project is to create a development board for the ESP32-S3 microcontroller so it can be used for developing firmware in future projects.

An SD card slot and 1S lithium battery charging circuit have been included on the board as these are peripherals that I plan on using in future projects.

The PCB also uses a series of Schottky diodes to enable powering the ESP32 from USB-C, External power, or a battery.
